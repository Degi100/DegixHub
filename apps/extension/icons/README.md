# Extension Icons

This folder should contain the following icon files:

- `icon16.png` - 16x16 pixels
- `icon32.png` - 32x32 pixels
- `icon48.png` - 48x48 pixels
- `icon128.png` - 128x128 pixels

## Temporary Solution

For now, you can use any PNG images with these dimensions, or generate them using a tool like:
- Figma
- Canva
- Online icon generators

## Design Suggestions

- Use the DegixHub gradient: `linear-gradient(135deg, #667eea 0%, #764ba2 100%)`
- Keep it simple and recognizable
- Make sure it works on both light and dark backgrounds

## Quick Fix

To get the extension working immediately, create simple colored squares:
1. Open any image editor
2. Create a new image with the required size
3. Fill with the purple gradient or solid color
4. Save as PNG with the correct name
